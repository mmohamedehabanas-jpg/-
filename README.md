# حق الله (Haqq Allah) - الويب الإسلامي

تطبيق إسلامي متكامل لمواقيت الصلاة، الأذكار والمسبحة، المصحف الشريف، متابعة الفروض والسنن، وبوصلة القبلة، ونظام «حق الله» التفاعلي وقت الصلاة.

## المميزات الرئيسية

- **مواقيت الصلاة الفلكية الدقيقة**: حساب فلكي دقيق باليوم واللحظة وفق 5 طرق حسابية معتمدة (الهيئة المصرية العامة للمساحة، أم القرى، رابطة العالم الإسلامي، ISNA، وطهران) مع دعم مذهب الجمهور والمذهب الحنفي لصلاة العصر، والعد التنازلي التفاعلي للصلاة القادمة.
- **نظام «حق الله» التفاعلي للصلاة**: شاشة تفاعلية روحية تسأل العبد عن أداء الفريضة، وتقدم نصائح نبوية وقرآنية لمعالجة أسباب التسويف والكسل والانشغال، مع دعاء الفك والبركة.
- **المصحف الشريف بالرسم العثماني**: تصفح كامل لـ 604 صفحة من مصحف المدينة النبوية مع فهرس السور الـ 114، الأجزاء والأحزاب، علامات السجدة، الفواصل، والوضع الليلي.
- **أذكار المسلم والمسبحة التفاعلية**: أذكار الصباح والمساء، أذكار النوم، وأذكار بعد الصلاة، مع مسبحة إلكترونية باهتزاز وتأثير صوتي وأهداف تسبيح مخصصة (33، 100، مفتوح).
- **متابعة الصلوات والنوافل (نظام النجوم الست)**: تقييم يومي (0-5 نجوم) للفروض، مع إضاءة النجمة السادسة الاستثنائية للسنن الرواتب (الفجر، الظهر، المغرب، العشاء، الضحى، والوتر) وورد القرآن الكريم، وسجل الأعذار والرخص الشرعية المعتبرة.
- **بوصلة القبلة التفاعلية**: حساب الزاوية الدقيقة للكعبة المشرفة والمسافة بالكيلومترات مع دعم حساس حركة الهاتف واهتزاز التطابق.
- **الأذان والتنبيهات**: مشغل أذان بصوت مكة المكرمة ونغمات إسلامية توافقية مع التحكم بمستوى الصوت.
